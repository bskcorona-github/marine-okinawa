# 宜野湾港マリーナ コンテンツ移植・トップページリニューアル 設計補遺

- 作成日: 2026-09-28
- 元データ: https://tagoo.jp/optour/ginowan-marina/（抽出結果 `docs/content/ginowan-marina.json` / `.md`）
- 本体設計書: `2026-09-28-marine-booking-design.md`

## 1. 前提と方針（ユーザーから方針一任）

元ページは 1 店舗ではなく「宜野湾港マリーナ」エリアのページで、3 事業者のプラン 11 件が掲載されている。

| 事業者 | プラン |
|---|---|
| ココマリン | パラセーリング 100/150/200m、パラセーリング＆フライボード、パラセーリング＆マリンパック、マリンパック トリプル、フライボード（7 件） |
| 釣船レクシー | ボートフィッシング 2 時間（1 件） |
| シーワークス沖縄アイランド | 慶良間貸切チャーター 7 時間・6 時間、ホエールウォッチング（3 件） |

**判断:** サイトは「宜野湾港マリーナの総合予約サイト」とし、ショップ（`shops`）= サイト 1 つのまま、**提供事業者（`operators`）** をメニューに紐づける。これは本体設計の「将来ポータル化」への第一歩で、事業者ごとのログイン・精算は引き続きスコープ外（管理はサイト運営者が一元で行う）。

## 2. 追加するデータ

| 追加 | 内容 |
|---|---|
| `operators` | 事業者名・紹介文・画像・予約締切の案内・キャンセル規定・天候時の扱い（表示用テキスト） |
| `menus.operator_id` | 提供事業者 |
| `menus.capacity_unit` | 定員の単位（`名` / `艇`）。貸切チャーターは 1 回 = 1 艇 |
| `menus.cutoff_prev_day_time` | 「前日 18:00 まで」型の予約締切（設定時は `booking_cutoff_min` より優先） |
| `menu_category` の追加値 | `parasailing` / `marine_sports` / `fishing` / `cruise` / `whale_watching` |
| `menu_translations` の追加列 | `summary`（一覧用の短い紹介）、`included`（料金に含まれるもの）、`conditions`（参加条件）、`notes`（注意事項）、`itinerary`（当日の流れ：jsonb）、`onsite_options`（現地オプション：jsonb） |
| `menu_images` | メニュー画像（並び順つき） |
| `menu_prices.season` | `on` / `off` / null（通年）。ココマリンのオン期・オフ期料金用 |
| `season_periods` | 事業者ごとのオン期の期間。その日がオン期かどうかで料金区分を出し分ける |
| `shops.profile`（jsonb） | トップページ用の見出し・キャッチコピー・紹介文・ヒーロー画像・住所・アクセス・駐車場・地図・近隣ホテル |

**季節料金:** 予約時の料金は「回の日付（ショップのタイムゾーン）が、そのメニューの事業者のオン期に含まれるか」で決める。`season` が null の料金区分は常に有効。メニュー詳細ページには両方の料金とオン期の説明を表示し、予約フォームにはその日に有効な料金だけを出す。

**貸切チャーター:** 出航時間の相談制（9〜11 時）だが、船は 1 日 1 組のため、1 日 1 回（9:00）・定員 1 艇とし、出航時間はメモで調整する運用にする。料金区分は出発港ごと（宜野湾発・那覇発・北谷発）。

**ホエールウォッチング:** 開催期間（1/4〜3/30）の間だけ回を作る（ルールの有効期間で表現）。

## 3. 画像

tagoo.jp への直リンクは避け、抽出した画像を `public/content/ginowan/` に保存して自サイトから配信する。公開前に、運営者が権利を持つ元画像への差し替えを推奨する（README に明記）。

## 4. トップページ（リニューアル）

1. ヒーロー（大きな写真 + 見出し + キャッチコピー + 「プランを探す」）
2. カテゴリで絞り込み（パラセーリング / マリンスポーツ / 釣り / クルーズ / ホエールウォッチング）
3. プラン一覧（写真・事業者・紹介文・所要時間・料金〜・対象年齢）
4. 予約の流れ（空き確認 → オンライン予約 → 当日現地払い）
5. 宜野湾港マリーナについて（紹介文）
6. 事業者紹介
7. アクセス（住所・行き方・駐車場・地図・近隣ホテル）

メニュー詳細ページも、写真ギャラリー・当日の流れ・料金に含まれるもの・参加条件・注意事項・キャンセル規定（事業者）・現地オプションを表示するように拡充する。

## 5. 取り込み

`npm run import:ginowan` で JSON からショップ情報・事業者・メニュー・料金・画像・回のルール・オン期を取り込む（slug で冪等）。取れなかった情報（電話番号・営業時間）は管理画面や後日の入力で補う。

## 6. スコープ外（今回）

- 管理画面での当日の流れ・現地オプション・ショップ紹介文の編集（取り込みデータを表示のみ）
- 事業者ごとのログイン・精算・事業者別の権限
- キャンセル規定の自動計算（段階2。今回は事業者のテキストを表示）
