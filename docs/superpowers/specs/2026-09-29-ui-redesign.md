# お客様向けサイト UI/UX リデザイン方針

- 作成日: 2026-09-29
- 前提: 元サイト（tagoo.jp）のデザインは踏襲しない。画像は運営者が後日用意するため、**画像がなくても完成して見える**デザインにする（画像が登録されれば置き換わる）

## 1. 目標

1. **日付から探せる**：旅行の予定日が決まっているお客様が、トップページで日付と人数を入れるだけで「その日に空いているプランと時間」が分かる
2. **3 画面で予約完了**：トップ → プラン詳細（日時を選ぶ） → 入力 → 完了。迷う分岐を作らない
3. **スマホ最優先**：タップ領域 44px 以上、重要な操作（日時を選ぶ・予約する）は画面下部の固定バーからいつでも押せる
4. **不安を先回りで解消**：料金に含まれるもの・支払いは当日現地・キャンセル規定・天候中止の扱いを、予約ボタンの近くで確認できる
5. **アクセシビリティ**：○△× は記号だけに頼らず、色＋文字でも伝える。コントラスト比 4.5:1 以上、キーボード操作可能、フォーカスが見える

## 2. ビジュアル

| 要素 | 方針 |
|---|---|
| 色 | 深い海の紺（ocean）を基調、ラグーンの青緑（lagoon）を差し色、行動を促すボタンだけ珊瑚色（coral）。背景は白と砂色（sand） |
| 文字 | 見出し：Zen Kaku Gothic New（太字）、本文：Noto Sans JP |
| 形 | 角丸 16〜24px、影は控えめ。情報はカード単位でまとまりを見せる |
| 画像がないとき | カテゴリごとのグラデーション＋アイコン＋波模様のカバーを表示（パラセーリング＝空色、釣り＝深い青、クルーズ＝ラグーン など） |

## 3. 画面構成

**トップ**
1. ヘッダー（ロゴ、ナビ、スマホはメニュー）
2. ヒーロー：キャッチコピー＋**空き検索パネル**（日付・人数・カテゴリ）
3. カテゴリのショートカット
4. プラン一覧：カードに所要時間・対象年齢・料金〜・事業者。日付を指定したときは **その日の空き時間（残り人数つき）** をカードに表示し、時間を押すとそのまま入力画面へ
5. 選ばれる理由（事実のみ：那覇から約 20 分、ネットで空き確認・即予約、当日現地払い）
6. 予約の流れ（3 ステップ）
7. よくある質問
8. 事業者紹介、アクセス（地図）
9. フッター

**プラン詳細**
- 見出し直下に「要点」（所要時間・対象年齢・集合・支払い・締切）
- 本文は目次（料金／当日の流れ／参加条件／キャンセル規定）で移動できる
- PC は右側に固定の予約パネル（カレンダー＋その日の時間）、スマホは下部に「料金〜・日時を選ぶ」固定バー

**予約入力**
- 進行状況（日時 → 入力 → 完了）
- 人数は ±ボタンのステッパー、合計金額を常に表示
- 右側（スマホは上部）に予約内容のまとめ（プラン・日時・集合場所・金額・当日現地払い）
- キャンセル規定への同意チェック

**予約完了**
- 予約番号を大きく（コピーできる）、カレンダーに追加（.ics）、集合場所・持ち物、次にすること

## 4. レビューの観点（改善ループで毎回確認する）

- 目標 1〜5 を満たしているか（スマホ 390px・PC 1440px の両方）
- 情報の優先順位（最初に目に入るべきものが目立っているか）
- 文言が具体的で、専門用語や社内用語がないか
- 空・エラー・満席・受付終了などの状態が分かりやすいか
- 事実でない宣伝文句を書いていないか
